# Участие в разработке

Спасибо за желание помочь Anki SOUND. Для крупных изменений сначала создайте issue, чтобы обсудить поведение программы и влияние на сохранность данных. В GitHub доступны шаблоны issue и pull request на немецком, английском и русском языках.

## Локальные проверки

Используйте окружение проекта:

```sh
.venv/bin/python -m unittest discover -s Tests -v
.venv/bin/python -m compileall -q Sources scripts Tests
git diff --check
```

Для нативной сборки macOS нужны Xcode Command Line Tools. Собирайте приложение в новый путь, чтобы не заменить существующую копию:

```sh
.venv/bin/python scripts/build_app.py --output 'previews/Anki SOUND review.app'
```

При изменении отбора, синтеза или упаковки дополнительно выполните ручную проверку на macOS с искусственным экспортом Anki. Не используйте личный профиль или коллекцию Anki в автоматических проверках. Для необязательной интеграционной проверки `scripts/verify_with_anki.py` нужен отдельный временный каталог коллекции.

Тесты не должны обращаться к внешним сервисам синтеза речи, выполнять платные запросы или читать личные файлы. Не добавляйте в коммиты пользовательские экспорты, аудио, модели голосов, журналы, кэши, локальные пути и собранные приложения.

## Запросы на слияние
