# Security policy

Report suspected vulnerabilities privately to the repository maintainer before opening a public issue. If GitHub private vulnerability reporting is enabled, use the repository's **Security** tab. Otherwise, request a private contact through the maintainer's GitHub profile before sending details.

Include the affected version, macOS version, a concise description, reproduction steps using synthetic data, and the potential impact. Do not send Anki exports, card text, audio, logs, credentials, or local paths.

Anki SOUND processes selected exports locally. Setup downloads pinned dependencies and voice models; their sources and separate terms are listed in [Third-party components and voice models](THIRD_PARTY.en.md).
