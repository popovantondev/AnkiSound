Anki SOUND

Добавляет локальную озвучку выбранным карточкам Anki и сохраняет отдельный проверенный пакет.

Выпуск · 3.4.11 macOS 13+ · Apple Silicon
Скачать для macOS Исходный код Python · Swift Руководство ↗

Перед запускомPython 3.9–3.12; интернет для первоначальной установки зависимостей и моделей. Приложение не нотарифицировано Apple.

Что внутри

Установка, функции, передача данных и проверка.

Установка

Шаги из раздела «Установка» руководства.

1. Распаковать всю папку в место, доступное для записи
2. Запустить SETUP.command (Python 3.9–3.12, нужен интернет)
загружает зафиксированные пакеты и русскую модель голоса (проверка SHA-256)
3. Запустить OPEN.command — откроется previews/Anki SOUND.app
4. Выбрать экспорт .apkg и режим, прослушать пример, запустить

Работает локально

Тексты и записи обрабатываются на вашем Mac. Только при установке один раз загружаются открытые пакеты и модели голосов из интернета.

Проверено

  • Автоматические проверки в GitHub Actions (macOS 15): компиляция, тесты, сборка приложения

  • Модель голоса проверяется по SHA-256 при установке
  • Версия 3.4.11 и журнал изменений
