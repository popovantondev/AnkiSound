Anki SOUND

Ergänzt ausgewählte Anki-Karten um lokale Sprachausgabe und erstellt ein separat geprüftes Paket.

Release · 3.4.11 macOS 13+ · Apple Silicon
Herunterladen für macOS Quellcode Python · Swift Anleitung ↗

Vor dem StartPython 3.9–3.12; Internet für die erste Installation von Paketen und Stimmen. Keine Apple-Notarisierung.

Was drin steckt

Installation, Funktionen, Datenverbindung und Prüfung.

Installation

Die Schritte aus „Installation“ in der Anleitung.

1. Gesamten Ordner an einen beschreibbaren Ort entpacken
2. SETUP.command starten (Python 3.9–3.12, Internet nötig)
lädt festgelegte Pakete und das russische Stimmenmodell (SHA-256-geprüft)
3. OPEN.command starten – öffnet previews/Anki SOUND.app
4. .apkg-Export wählen, Modus wählen, Vorschau anhören, starten

Läuft lokal

Texte und Aufnahmen werden auf Ihrem Mac verarbeitet. Nur die Einrichtung lädt einmalig öffentliche Pakete und Stimmenmodelle aus dem Internet.
