Anki SOUND

Ergänzt ausgewählte Anki-Karten um lokale Sprachausgabe und erstellt ein separat geprüftes Paket.

Release · 3.4.11
Herunterladen für macOSAnleitung ↗

Vor dem StartPython 3.9–3.12; Internet für die erste Installation von Paketen und Stimmen. Keine Apple-Notarisierung.

So funktioniert es

  1. Anki-Karten
  2. Stimme einrichten
  3. Sprachausgabe ergänzen

Erste Schritte

Den gesamten Ordner an einen beschreibbaren Ort entpacken. SETUP.command, danach OPEN.command starten; einen .apkg-Export wählen.
