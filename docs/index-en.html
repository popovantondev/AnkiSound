What's inside

Installation, features, data flow and checks.

Installation

The steps from “Installation” in the guide.

1. Extract the whole folder to a writable location
2. Run SETUP.command (Python 3.9–3.12, internet required)
downloads pinned packages and the Russian voice model (SHA-256 checked)
3. Run OPEN.command – opens previews/Anki SOUND.app
4. Choose an .apkg export and a mode, listen to the preview, start

Runs locally

Text and audio are processed on your Mac. Only the setup downloads public packages and voice models from the internet, once.
