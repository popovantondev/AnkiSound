# Политика безопасности

До создания публичного issue сообщите о предполагаемой уязвимости конфиденциально владельцу репозитория. Если в GitHub включён приватный приём сообщений об уязвимостях, используйте вкладку **Security**. Иначе сначала запросите у владельца приватный способ связи через его профиль GitHub.

Укажите затронутую версию, версию macOS, краткое описание, шаги воспроизведения на искусственных данных и возможные последствия. Не отправляйте экспорты Anki, текст карточек, аудио, журналы, учётные данные или локальные пути.

Anki SOUND локально обрабатывает выбранные экспорты. Установщик скачивает закреплённые зависимости и модели голосов; источники и отдельные условия приведены в документе [Сторонние компоненты и модели голосов](THIRD_PARTY.ru.md).
