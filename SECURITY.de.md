# Sicherheitsrichtlinie

Melden Sie vermutete Sicherheitslücken vertraulich an die Projektverantwortlichen, bevor Sie ein öffentliches Issue eröffnen. Falls die private Sicherheitsmeldung in GitHub aktiviert ist, nutzen Sie die Registerkarte **Security**. Andernfalls fragen Sie über das GitHub-Profil der Projektverantwortlichen nach einem privaten Kontaktweg.

Nennen Sie betroffene Version, macOS-Version, eine kurze Beschreibung, künstliche Reproduktionsschritte und mögliche Auswirkungen. Senden Sie keine Anki-Exporte, Kartentexte, Audios, Protokolle, Zugangsdaten oder lokalen Pfade.

Anki SOUND verarbeitet ausgewählte Exporte lokal. Die Einrichtung lädt festgelegte Abhängigkeiten und Sprachmodelle herunter; Quellen und gesonderte Bedingungen stehen in [Drittkomponenten und Sprachmodelle](THIRD_PARTY.md).
